## 🎯 Como Usar no Seu Windows:

### 1. Clone o repositório atualizado:
```bash
git pull origin main
# ou
git clone https://github.com/SEU_USUARIO/site-generator.git
cd site-generator
npm install
```

### 2. Execute:
```bash
# Modo desenvolvimento (navegador)
npm run dev

# Modo Electron Desktop
npm run electron:dev

# Build para produção (.exe)
npm run electron:build
```

### 3. Teste as novas funcionalidades:
1. Abra o app
2. Selecione o template "Restaurante" 
3. Configure nome, cores, seções
4. Clique na aba "Preview" para ver em tempo real
5. Exporte e veja a estrutura completa
